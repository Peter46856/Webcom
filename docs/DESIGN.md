# Design direction

## October 31 expansion

Keep the six original color tokens, Space Grotesk headings, DM Sans body, and left-aligned type. Add depth through industry-specific operating problems and service-specific scenarios rather than repeating homepage cards. Industry pages connect problems to capabilities and discovery questions; the delivery page uses sequential checkpoints, engagements use comparable deliverables, and FAQs use accessible native disclosures.

The private workspace separates administration from marketing navigation. A quiet fixed sidebar connects overview, inquiry inbox, and blog studio. The inbox is a selectable list/detail view; the editor separates metadata from Markdown with explicit save/publish actions. On mobile, navigation becomes a compact horizontal group and both tools stack vertically. Drafts, published content, loading, failures, and empty states have distinct visible feedback.

## Plan

The visual anchor is an interactive systems map connecting interfaces, data, events, and network access. It expresses WebCom's combination of software development and infrastructure engineering without people, generic stock imagery, or decorative robots.

- Canvas: Midnight navy `#090d16`
- Surface: Charcoal blue `#131c2e`
- Signal: Cyan `#00f2fe`
- Secondary signal: Indigo blue `#4facfe`
- Primary text: Light gray `#f8fafc`
- Secondary text: Slate `#94a3b8`
- Type: Space Grotesk headings with close tracking; DM Sans body with relaxed line height. Left-aligned content and legible line lengths.

## Review against the brief

The requested dark surfaces, border glows, and glass treatments are retained. To avoid making the page a generic SaaS dashboard, the hero uses a system architecture explorer, the three case studies have domain-specific illustrations, and articles use an editorial layout. Cyan marks connection and selection rather than coloring arbitrary words in headlines. Numbered markers appear only in the actual delivery process.

## Interaction and accessibility

Keyboard focus is visible; the page has a skip link, semantic landmarks, a mobile menu, and native form controls. Diagram selections are buttons with pressed state. Blog search provides result counts and a reset path. Form errors retain the user's work. Reduced-motion preferences disable the subtle diagram signal animation. The geometric monogram is an inline vector asset with no external imagery dependency.
